# 镜头标注与选片

## 一行对应一个可直接剪入成片的区间

先看原片，再确定精华片段。起秒取主体、动作或空间已经清楚的位置，止秒取本次有效内容结束的位置。区间按原片时间轴记录为 `[起秒, 止秒)`。开机找角度、等待、失焦或无意义晃动占据的秒数可以空出。多个精华段分别入表。按实际画面划边界，切分时保留原片编号。

优先保留连续、完整且至少 3 秒的区间。原镜头本身较短，且在 3 秒以内已切换分镜时，可以保留实有长度。回放时从表中起秒开始，到止秒停止。使用原片解码时间核对边界，并检查第一帧、最后一个有效画面以及动作的连续性。

## 标签只描述当前区间

| 字段 | 判断方法 |
| --- | --- |
| 画面类型 | 按实际拍到的镜头选类型。展示工人、材料桶和施工动作时，逐项核实每个所选类型在该区间内成立。 |
| 素材类别 | 记录剪辑师能用这段画面说明的业务主题，例如覆盖批刮工艺或地面服务。类别与画面类型分别判断。 |
| 画面描述、主动作 | 写明谁或什么、操作对象和可观察的动作。只拍到上料时，描述止于上料。 |
| 空间、部位、阶段 | 依据画面或有明确出处的工程记录归类。能确认是翻新前原貌时可标旧房旧态，外观完好的房间也适用。 |
| 材料、基层 | 区分正在施用的材料与承接施工的表面。已确认木地板时填木地板。新概念应补入对应字典并定义适用条件。 |
| 人数、角色、动作 | 逐段记录实际出镜人数、可核实角色与动作。未经确认的具名角色留待复核。 |
| 景别、运镜、声音 | 以该段主体在画面中的比例、镜头实际运动和原声判断。跨越不同分镜时分别记录。 |

某个维度看不清时，按对应字典记录待核或无法判断。有证据证明该维度没有元素时才填“无”。房间能确认、材料待核的片段仍可按房间检索。

## 检索与回看

本地素材使用本地表及其字典，云端素材使用云端表及其字典。不同维度的条件必须落在同一原片的同一秒段。用一行的画面类型搭配另一行的空间会引入错误候选。用户调整表格列和字典时，应复核相应字段映射及检索结果。

例如一段拍到在墙上批刮，另一段拍到地面，就能分别检索这两段。“地面上批刮”需要同一秒段同时拍到地面和批刮。优先展示满足条件的候选，有几条给几条。工程内展示过的原片按工程去重，其他工程可以再次使用。
