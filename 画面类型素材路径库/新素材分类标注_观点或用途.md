# 选片用途与画面类型

| 观点或用途 | 对应性质 | 先找的画面类型 | 实看核对 | 不能当主画面 |
|---|---|---|---|---|
| 开场、提问、转折、吸引注意 | 直接展示 | 人物对镜头（V01）；成品空镜（V13）；手摸成品（V16）。变化型开场可试同镜转场（V14） | 第一个动作能否抓住注意 | |
| 点赞、关注、收藏 | 直接展示 | 人物对镜头（V01）。握手沟通可作备选 | 有没有面向镜头的招呼或手势，动作要完整 | 虚构的点赞数字 |
| 到场、沟通、带队、量房安装 | 直接展示 | 上门搬物（V03）；握手沟通（V02）；量房水电安装（V04）；人物在现场（V24） | 分清上门与下班、安装与测量、沟通与单纯同框 | |
| 旧房子、老楼、改造反差 | 直接展示 | 旧房旧态（V12）；老楼或城市外景（V21）；同镜转场（V14），或旧态接成品空镜（V13） | 发霉、油污、砖缝、起皮要看见具体部位。外景只能交代地域 | 只能确定同项目时，不要当成同一房间 |
| 不用搬家、边住边改 | 直接展示 | 家具还在、人还过得去；铺保护膜（V09）；屋里挪家具（V03） | 家具是否仍在，动的是哪一处 | 整户打包搬走、去住酒店。短暂挪家具不要说成整户搬家 |
| 还得搬出去、住酒店 | 直接展示 | 真实的打包、搬离 | 要看得出是往外搬 | 家具还在、人还在家里生活的镜头 |
| 不拆不砸、省了拆除 | 直接展示。若同时讲省钱，费用只能示意 | 批刮（V05），最好同时看见旧砖和新料 | 原砖还在，上面是覆盖 | 正在砸砖当主画面。拆砸只可作很短的反例 |
| 以前敲砖、传统翻新要砸 | 直接展示 | 拆砸贴砖（V08）或铲墙（V07） | 要看得出这是旧方法 | 接成「我们正在砸」，或直接当成微陶泥工艺 |
| 灰尘满天飞、噪音大 | 直接展示 | 看得见扬尘或拆砸 | 尘土或敲砸要在画面里 | 安静的手工批刮 |
| 不扰民、没有灰尘 | 直接展示 | 手工批刮、分区围起来、人照常走过 | 动作安静，人还过得去 | 后期加上的粉尘，或正在砸的主画面 |
| 材料、包装、用料 | 直接展示。品牌和型号另核实物 | 料桶、取料、搅拌（V11）。按实拍再扩到批刮（V05）、滚涂（V06） | 包装、质地、上墙是三种拍法。开桶即用要看见开桶 | 微陶泥工艺句不用微岩石、水洗石 |
| 喷水、弯折、刮擦等性能 | 需事实依据。画面只演示动作 | 喷水（V18）；弯折样板（V19）；刮擦（V20） | 测试对象、接触动作和结果都要可见 | 用演示代替检测报告。防水、耐磨性能需核对检测依据 |
| 做完了、能住、空间能用 | 直接展示完成状态。工期数字另核 | 成品空镜（V13）；成品里的人（V15）；手摸成品（V16）；日常清洁（V17） | 要看见设施或具体家务，空间要认得出来 | 旧状或正在拆除，不能表示已经能住 |
| 价格、补贴、工期、身份、质保 | 需事实依据，或语境承接。画面只作示意 | 人物对镜头（V01）、握手沟通（V02），或对应该句的工序 | 画面适配和事实依据分开写 | 普通施工证明价格；完工画面单独证明当天入住；伪造报价单 |
