# 把两句字幕配到同一条演示原片

仓库附带一条 9 秒的竖屏动画。先播放 [演示原片](synthetic-scene-01.mp4)，再对照[秒段工作簿](synthetic-cloud-segments.xlsx)。影片开始的 1.25 秒是静止准备画面。抹板从 1.25 秒开始移动，到 5.25 秒切镜，随后画面展示沿地面边缘铺胶带。

| 字幕 | 画面类型 | 素材类别 | 原片起秒 | 原片止秒 |
|---|---|---|---:|---:|
| 镜头中抹板在墙面移动并留下色带。 | V05 · 施工·批刮覆盖 | 覆盖批刮工艺 | 1.25 | 5.25 |
| 把保护胶带铺到地面边缘。 | V09 · 铺保护膜、贴胶带 | 地面服务 | 5.25 | 8.75 |

## 从命令行查表

在仓库根目录运行。这个检查只需 Python 标准库，离线读取本地和云端两份演示表。

```powershell
py -B examples/verify_demo.py
```

预期两份表都返回上表的两个区间。再用 `V05 + 地面服务` 组合查找时，两份表都应返回 `[]`。抹板在第一段，地面胶带在第二段。两项条件必须落在同一起止秒上。

## 在桌面工作台选片

先按[项目启动说明](../README.md)装好依赖、FFmpeg 和 FFprobe。在仓库根目录运行以下命令。第一条命令初始化本机配置，并将演示视频登记到本机素材索引；第二条启动工作台。

```powershell
.\cutframe-studio\.venv\Scripts\python.exe -B examples/verify_demo.py --index
.\cutframe-studio\.venv\Scripts\python.exe cutframe-studio/app.py
```

1. 在浏览器打开 `http://127.0.0.1:4380`。新建演示工程，把上表两句字幕依次填入文案，保存工程。
2. 在「配音与试听」导入 [4 秒节拍音](demo-timing.wav)。开头和第 2 秒各响一声，方便核对两句字幕的分界。在「字幕与样式」导入 [演示字幕](demo-subtitles.srt)，保存字幕修改，再进入「选片与分镜」。
3. 选择「本地素材 · 演示素材」。点第一句，查看 V05 候选并从原片 1.25 秒处预览。演示字幕长 2 秒，预览采用的片长和素材表记录的完整可用区间可以不同。
4. 要独立复测第二句，另建一个演示工程，导入相同节拍音和字幕，先选第二句。V09 应定位到原片 5.25 秒。同一工程按原片去重，先查过第一句会影响第二句的候选。

首次初始化自动设置素材根别名 `demo`、目录为当前仓库的 `examples`、`path_aliases` 为 `["examples"]`。使用已有配置时，在 `local/cutframe/config.json` 的 `roots` 中补上以下条目，把 `path` 改为自己机器上的绝对路径，再执行上面的登记命令。自定义了 `CUTFRAME_STATE` 时使用该目录内的 `config.json`。

```json
"demo": {
  "path": "D:/CutFrame/examples",
  "path_aliases": ["examples"],
  "label": "演示素材",
  "role": "raw",
  "origin": "local"
}
```

素材 ID 取 `SHA-256("demo/synthetic-scene-01.mp4")` 的前 32 个十六进制字符，值为 `9efb45f0d16e4a1b2756ba04e9741ccf`。仓库可移动；更换根别名或修改素材相对文件名会改变 ID。

命令行检查覆盖观点匹配、两套表格的秒段读取、同段组合筛选和本机素材登记。桌面步骤供核对浏览器中的播放、选入和工程内去重。
